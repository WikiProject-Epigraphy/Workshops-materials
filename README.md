# Guidelines
1. Choose one inscription from the folder of the workshop you are attending
2. Write down the main metadata (findspot, material, date...)
3. Match them to the properties in Wikidata ([location of discovery P198](https://www.wikidata.org/wiki/Property:P189), [made from material P186](https://www.wikidata.org/wiki/Property:186), [inception P571](https://www.wikidata.org/wiki/Property:P571)...)
4. Write down the main values (Rome, marble, "500 AD", "inventory number 2"...)
5. Match them to the items in Wikidata ([Rome Q220](https://www.wikidata.org/wiki/Q220), [marble Q40861](https://www.wikidata.org/wiki/Q40861), time and strings datatypes)
6. Edit in Wikidata
